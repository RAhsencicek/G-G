# 🌱 GreenGuard - Bitki Bakım Uygulaması

Modern ve interaktif bir bitki bakım takip uygulaması.

## ✨ Özellikler

- 🏠 **Pixel Art Dashboard** - İnteraktif oda görünümü
- 🌿 **14 Bitki Slotu** - Hover ile açılan bilgi kartları
- 💧 **Bakım Takibi** - Sulama, gübreleme, budama
- ❤️ **Sağlık Skoru** - Otomatik hesaplanan bitki sağlığı
- 🎨 **Modern UI** - Fade-in animasyonları, rounded corners

## 🛠️ Teknolojiler

- **Framework:** .NET 10 Windows Forms
- **UI:** DevExpress + Standard WinForms
- **Database:** SQL Server LocalDB + Entity Framework Core
- **Design:** Pixel Art, Pastel Green Theme

## 🚀 Kurulum

1. Repository'yi klonlayın
2. Visual Studio 2022+ ile açın
3. NuGet paketlerini geri yükleyin
4. Veritabanını migrate edin: `dotnet ef database update`
5. F5 ile çalıştırın
